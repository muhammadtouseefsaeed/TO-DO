An interactive To-Do List App that helps users manage their daily tasks efficiently. Users can add new tasks, mark them as completed, and delete them using a clean, minimal, and responsive interface.

🔹 Features

Add, edit, and delete tasks easily

Mark tasks as completed

Optional data persistence using local storage

Responsive and modern UI

Smooth animations and clear layout

🔹 Technologies Used

HTML

CSS

JavaScript

🔹 How to Use

Clone or download the repository:

git clone https://github.com/your-username/todo-app.git


Open index.html in your browser.

Start adding, managing, and completing your tasks.
